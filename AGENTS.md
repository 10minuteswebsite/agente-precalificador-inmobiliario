# Instrucciones del proyecto

- GitHub es la única fuente permanente de verdad.
- Al comenzar una sesión, lee primero `moving.md`; después carga solo el contexto que el siguiente paso necesite.
- Para trabajo sustancial, aplica las reglas canónicas de `10minuteswebsite/AI-Playbooks`, cargadas mediante `opencode.json`.
- El módulo es un súper poder aditivo del Enrutador: no mezcla leads, no sustituye al conversador y no almacena datos operativos.
- Preserva contratos, aislamiento por organización/conversación, idempotencia y Agent DNA como fuente de verdad.
- Verifica cambios con `npm test`; usa `npm run verify:prequalifier` solo cuando exista acceso al entorno configurado.
